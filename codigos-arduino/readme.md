## Códigos de Arduino

En esta carpeta se contienen todos los códigos de Arduino para los proyectos que hemos ido montando en el Club de Vuelo.

### Contenido del directorio

* `readme.md`: este documento, como índice de contenido.
* `Collective/`: Los sketches para el funcionamiento del colectivo.
* `foc-angle-control-mt6701/`: El código utilizando la librería de control FOC para mover un motor BLDC (punto de partida para proyectos con FFB).
* `Joystick/`: códigos para el proyecto del Joystick (grip y base).
* `pruebas-sensores/`: códigos para comprobar que funcionan varios aspectos del arduino, como los sensores I2C.
